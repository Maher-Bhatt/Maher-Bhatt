<a id="kalki"></a>
## K.A.L.K.I. · voice AI for Windows

<div align="center">
<img src="./assets/kalki-flow.svg" alt="K.A.L.K.I. cognitive router: voice, PWA HUD and Telegram inputs routed to Groq, vision and offline Ollama models" width="100%"/>
</div>

A fully voice-controlled desktop assistant, live on the Microsoft Store. A multi-model router sends conversation to Groq LLaMA-3.3-70B and vision to LLaMA-4-Scout, with offline Ollama as the fallback. It ships a hardware-bound DPAPI secure vault, semantic memory, a cybersecurity toolkit (Webscan, Shodan OSINT, CVE intel), a state-reactive PWA HUD and Telegram control.
